# Junkyard Brawl

A retro, slightly-apocalyptic Roblox free-for-all platform fighter: punch, shove and hurl junk to knock rivals off
crumbling floating platforms. Two modes — **Classic** (HP + stocks) and **Casual** (knockback % only).

- Design spec: [docs/PROJECT_BIBLE.md](docs/PROJECT_BIBLE.md)
- Progress log, build order, setup and conventions: [CLAUDE.md](CLAUDE.md)

## Quick start

```sh
rokit install                      # Rojo, Selene, StyLua, Lune (versions in rokit.toml)
rojo serve                         # then Connect from the Rojo plugin in Roblox Studio
```

Or download the `JunkyardBrawl-place` artifact from the latest CI run and open the `.rbxl` in Studio.
